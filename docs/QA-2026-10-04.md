## Amalda bajarilgan tekshiruv

`node tools/serve-site.cjs` orqali faqat 127.0.0.1:8765 manzilida mahalliy server ishga tushirildi.
UZ: http://127.0.0.1:8765/index.html; RU: http://127.0.0.1:8765/ru.html.

`node tools/check-static.cjs` muvaffaqiyatli tugadi:

- Ikkala HTML, CSS, app.js, config.js va favicon HTTP 200 qaytardi.
- HTTP orqali olingan fayllar diskdagi fayllarga baytma-bayt mos.
- Har sahifada 7 bo‘lim, takrorlanmagan IDlar, viewport va to‘g‘ri lang atributi bor.
- Ichki bo‘lim havolalari va mahalliy aktivlar mavjud.
- UZ/RU til havolalari HTMLda to‘g‘ri manzilga yo‘naltirilgan (bosib tekshirilmagan).
- app.js va config.js sintaksisi o‘tdi; `node --check` ham xatosiz tugadi.
- Tarqatiladigan konfiguratsiya `demo: true`, kontaktlar bo‘sh; uch kontakt HTMLda #contact manzilida.

Bu statik/HTTP tekshiruvlar brauzerda ishlashning isboti emas.
O‘lchovlar va fayllarning SHA256 qiymatlari `QA-2026-10-04.json`da.

## Tuzatish va xavfsiz tekshiruv tartibi

Tasdiqlangan sayt nuqsoni topilmadi; sayt fayllari o‘zgartirilmadi.
Brauzer tekshiruvi bo‘lmagani sabab sayt xatosiz deb xulosa qilinmaydi.
Hech kimga xabar yuborilmadi, qo‘ng‘iroq qilinmadi yoki tashqi kontakt havolasi ochilmadi.

Keyingi sessiyada brauzer/Computer Use ulanishi ishlashi kerak. Serverni yuqoridagi buyruq bilan
ishga tushiring (port band bo‘lsa, mavjud serverni tekshiring). Ikkala tilni 375, 768, 1440 px
va Notiondagi eski qabul mezonidagi 360/390 px kengliklarda tekshiring.
To‘liq sahifa skrinshotlari, ochiq mobil menyu va demo dialogini loyiha ichiga saqlang.
Har sahifani oxirigacha ko‘rib chiqing; konsol, scrollWidth/clientWidth va klaviatura fokusini tekshiring.
Konfiguratsiya sinovini faqat vaqtinchalik QA nusxasida bajaring: demo true;
demo false + bo‘sh/yaroqsiz kontaktlar; demo false + test kontaktlari.
Test uchun example.com HTTPS xarita URLi, namunaviy Telegram username va test telefonidan
foydalanib href/target/rel qiymatlarini tekshiring; tashqi havolalarni bosmang.
Tarqatiladigan config.js demo rejimida qolishi kerak.

Topilgan nuqsonlarni tuzatib, tegishli til/kengliklarni qayta sinang.
