# EduStart UZ/RU — инструкция
Версия 0.1.0 от 03.10.2026. Предварительный пакет для проверки, не финальный релиз.

Откройте `site/index.html` или `site/ru.html` после распаковки ZIP. Переключение языка работает через ссылки между страницами; сборка и npm не нужны.

## Настройка
1. В `site/config.js` укажите название центра (`brand`), Telegram username без @, телефон в международном формате без пробелов, HTTPS-ссылку на карту и адрес/часы работы на двух языках. Секретные ключи в этот файл не добавляются.
2. Отредактируйте содержимое ОБОИХ HTML-файлов: курсы, преподавателей, условия, FAQ, `<title>` и описание. Параметр `brand` не изменяет заголовок вкладки автоматически. `docs/COPY_UZ_RU.json` содержит исходные тексты для справки, но не управляет HTML.
3. Используйте реальные сведения и изображения, на которые у вас есть права. Не оставляйте демонстрационный профиль преподавателя на рабочем сайте.
4. Цвета задаются в `:root` файла `styles.css`.
5. После замены всех примеров установите `demo: false`. В демонстрационном режиме контактные кнопки показывают окно с пояснением. Если отдельный контакт пуст или неверен, эта кнопка продолжит показывать окно даже после выключения деморежима.
6. Загрузите ВСЕ файлы из `site` в корневой каталог статического хостинга. Проверьте опубликованный сайт и контакты самостоятельно.

## Состав и ограничения
Две языковые HTML-страницы с одинаковыми семью разделами, CSS, JS, настройки и значок. Это не тема WordPress, Framer или Webflow. В пакет не входят домен, хостинг, CRM, n8n, приём платежей, аналитика и хранение заявок. Ссылка Telegram открывает чат, а не отправляет сообщение. Контактная конфигурация требует JavaScript.

Перед продажей проверьте мобильную версию, оба языка, меню, FAQ, управление клавиатурой и реальные ссылки. Визуальная проверка браузером для версии 0.1.0 пока не завершена.
